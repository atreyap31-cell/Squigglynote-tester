How testing works

Every two hours, or when you press Run test now, the Squiggly server opens the live site in a private headless Chrome window and uses it like a person would.

AI end to end

Asks SquigglyBot, shortens text, reads aloud with Kokoro and transcribes a real spoken recording with Whisper.
